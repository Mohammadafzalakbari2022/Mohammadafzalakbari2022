خیاط (Khayat)

برنامهٔ مدیریت دوخت‌خانه — دانلود و نصب

دانلود برای اندروید (APK) باز کردن نسخهٔ وب (بدون نصب) راهنمای کامل نصب به دری (متن) آیفون — راهنما (TestFlight / وب)
اندروید: بعد از دانلود، در تنظیمات به Chrome اجازهٔ «نصب برنامه‌های ناشناس» بدهید، سپس فایل APK را باز کنید.
آیفون: از لینک APK نمی‌توان نصب کرد — از نسخهٔ وب یا TestFlight استفاده کنید.

English: Android APK via GitHub Releases. Web app on Cloudflare Pages. iOS requires App Store or TestFlight — see INSTALL_FA.md.
