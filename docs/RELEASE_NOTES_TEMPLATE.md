## Khayat (خیاط) — v3.6.0

**Android (side-load):** download `Khayat-android.apk` below. Dari install guide: [INSTALL_FA.md](https://github.com/Mohammadafzalakbari2022/Mohammadafzalakbari2022/blob/main/docs/INSTALL_FA.md)

**Web:** [Open in browser](https://pride-v3-web.pages.dev) (deploys from `main` via GitHub Actions).

**iPhone:** direct APK install is not supported — use TestFlight / App Store when available.

**API:** `https://mohammadafzalakbari2022.onrender.com`
